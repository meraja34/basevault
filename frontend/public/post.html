Your files deserve better than "trust me bro" storage. Here's what BaseVault does differently.

💾 What is BaseVault?

A platform where your actual file bytes are stored inside a smart contract on Base. Not a hash. Not a link. The real file, on-chain, forever.

⚡ How it works

  1. Connect your wallet (Coinbase Smart Wallet recommended)
  2. Pick a file (up to 50 MB, any type)
  3. Choose Public or Private (encrypted with wallet + password)
  4. File gets split into 24 KB chunks
  5. All chunks stored on-chain in one batch transaction
  6. Done. Your file lives on Base forever

🔴 Why not IPFS / Arweave / Filecoin?

IPFS Files disappear if nobody pins them. You trust Pinata, not the chain.
Arweave Separate chain, separate wallet, separate ecosystem.
Filecoin Same problem, different chain.
BaseVault Actual bytes on Base. Same chain as your wallet. No external dependency.

✅ What makes it different

✓ Truly on-chain storage, not just a hash
✓ AES-256 encrypted private files
✓ SHA-256 document certification
✓ Batch uploads via Smart Wallet
✓ Farcaster MiniApp with auto-connect
✓ Permissionless, no signup needed
✓ Permanent and immutable storage
✓ Any file type up to 50 MB

🎯 Who is it for?

  • Anyone who wants censorship-resistant file storage
  • Legal proof and document certification
  • Private file storage on a public blockchain
  • Developers who need verifiable on-chain data
